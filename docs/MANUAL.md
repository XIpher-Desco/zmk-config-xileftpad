# xileft pad ユーザーマニュアル（v1 基板）

左手用キーパッド **xileft pad**（27キー + ロータリーエンコーダ3個 / ZMK / Bluetooth 対応）の使い方。
組み立て済みの実機を、はじめて動かすところからの手順です。

> このマニュアルは **v1 基板**（パターンカット＋ジャンパのリワーク済み）用です。
> ファームウェアは必ず `xileft_pad.uf2` を使ってください（`xileft_pad_v2.uf2` はピン定義が違います）。

---

## TL;DR

1. GitHub Actions の Artifacts から `xileft_pad.uf2` を落とす
2. XIAO の**リセットボタンを素早く2回押す** → 出てきた USB ドライブに `.uf2` をコピー
3. まず **USB でつないで**全キー・全エンコーダを確認
4. Bluetooth は **3段目・左から2番目のキーを押しながら**プロファイルを選ぶ
5. キーマップは **ZMK Studio**（実機で編集）か `config/xileft_pad.keymap`（ファイルで編集）

---

## キーの数え方

このマニュアルでの位置の呼び方です。

```
1段目  ■ ■ ■ ■            ← 4キー
2段目  ■ ■ ■ ■ ■          ← 5キー
3段目  ■ ■ ■ ■ ■
4段目  ■ ■ ■ ■ ■
5段目  ■ ■ ■ ■ ■
レバー ■ ■ ■              ← 3キー
エンコーダ ①②③           ← 回すノブ 3個
```

## 1. ファームウェアを用意する

キーマップや設定を変えたら、GitHub にプッシュするだけでビルドされます。

```sh
git add .
git commit -m "keymap update"
git push
```

1. GitHub のリポジトリ → **Actions** タブ → 最新の実行を開く
2. 下の **Artifacts** から `xileft_pad` をダウンロード（zip）
3. zip を展開すると `xileft_pad.uf2` が入っている

> ビルドは数分かかります。実行が赤くなっていたらログを確認してください。

---

## 2. 書き込む

1. XIAO を USB でパソコンにつなぐ
2. XIAO 上の**リセットボタンを素早く2回押す**（ダブルクリックの要領）
3. `XIAO-SENSE` のような名前の **USB ドライブ**がマウントされる
4. そこに `xileft_pad.uf2` を**コピー**する
5. コピーが終わると自動で再起動し、ドライブが消える → 書き込み完了

> **注意**: RP2040 用の `.uf2` や `xileft_pad_v2.uf2` とは互換性がありません。取り違えに注意。
> ドライブが出てこないときは、ダブルクリックの間隔を変えて何度か試してください。

**電源が入ると XIAO のオンボード緑 LED が点灯します。** これが電源インジケータです。

---

## 3. まず USB で動作確認する

**無線より先に、必ず USB 接続で確認してください。** いきなり Bluetooth から始めると、
配線の問題か無線の問題かの切り分けができません。

チェックすること:

- 27 キーすべてが反応するか
- エンコーダ 3 個すべてが反応するか
- エンコーダの**回転方向**が期待どおりか（時計回りで意図した方向に動くか）
- 1 ノッチ回したときの反応量が適切か（効きすぎ／効かなすぎ）

デフォルトのエンコーダ動作（BASE レイヤ）:

| | 左回し | 右回し |
| --- | --- | --- |
| エンコーダ① | `-` | `=` |
| エンコーダ② | 下スクロール | 上スクロール |
| エンコーダ③ | `\` | `]` |

> 反応しない／方向が逆／効きが強すぎる場合は、リポジトリの `README.md`
> 「最初にやること」の項に調整方法があります。

## 4. Bluetooth でつなぐ

**3段目・左から2番目のキーを押している間だけ「BT レイヤ」になります。**
このキーを押しっぱなしにしながら、下のキーを押してください。

| BT レイヤのキー | 動作 |
| --- | --- |
| 1段目の 4 キー | 接続先プロファイル **1〜4** に切り替え |
| 2段目・1番目 | 接続先プロファイル **5** に切り替え |
| 2段目・2番目 | **現在のプロファイルのペアリング情報を消去** |
| 2段目・3番目 | 電源インジケータ LED の消灯 / 点灯 |
| 2段目・4番目 | 出力先を **USB** に固定 |
| 2段目・5番目 | 出力先を **Bluetooth** に固定 |

### はじめてのペアリング

1. USB ケーブルを抜く（または 2段目・5番目で出力先を Bluetooth にする）
2. BT レイヤで**空いているプロファイル**（1〜5）を選ぶ
3. パソコン／スマホの Bluetooth 設定を開く
4. **「xileft BLE」** が出てくるので追加する

プロファイルは 5 つまで登録でき、BT レイヤのキーで切り替えるだけで
接続先のデバイスを行き来できます。

### つながらないときは

1. BT レイヤで**そのプロファイルを選んだ状態**で、**2段目・2番目**を押してペアリング情報を消す
2. デバイス側の Bluetooth 設定からも「xileft BLE」を**削除**する
3. もう一度ペアリングし直す

> 両方消してからやり直すのが確実です。片方だけ消すと再接続に失敗しがちです。

### 電池について

リワーク済みの v1 基板は、**電池残量が接続先デバイスの Bluetooth 画面に表示されます**。
残量表示が 100% や 0% に張り付く場合は、リワークのカットが不完全な可能性があります。

電池を長持ちさせたいときは、**BT レイヤの 2段目・3番目**で緑 LED を消しておいてください
（消灯状態は再起動しても保持されます）。USB 給電中は気にしなくて構いません。

## 5. キーマップを変える

方法は 2 つあります。**どちらか一方に決めて使ってください**（後述の注意を参照）。

### A. ZMK Studio で実機を直接編集する（手軽）

1. キーボードを **USB** でパソコンにつなぐ
2. Chrome / Edge で <https://zmk.studio/> を開く
3. キーボードを選んで接続する
4. **アンロック操作**: `4段目・左端のキーを長押ししたまま、1段目・左端のキーを押す`
5. アンロックされたら、画面上でキーをクリックして割り当てを変更 → 保存

変更は即座に実機へ書き込まれ、再ビルドは不要です。

> **エンコーダの回転動作は Studio では変更できません**（ZMK 側が未対応）。
> エンコーダを変えたいときは下の B の方法を使ってください。

### B. ファイルを編集して再ビルドする（フル機能）

1. `config/xileft_pad.keymap` を編集する
2. `git push` する
3. 「1. ファームウェアを用意する」「2. 書き込む」をもう一度行う

レイヤ、エンコーダ、複雑な挙動（ホールドタップなど）はすべてここで設定できます。

### ⚠️ A と B の関係（重要）

**ZMK Studio で一度でもキーマップを編集すると、以降 `.keymap` ファイルを書き換えて
再書き込みしても反映されなくなります。** 実機側の設定が優先されるためです。

ファイル編集を再び有効にするには、ZMK Studio で
**「Restore Stock Settings」** を実行してください。実機側の変更は破棄され、
`.keymap` ファイルの内容に戻ります。
